#  LindaAfya

LindaAfya is a modern healthcare web application designed to streamline health services, patient tracking, and access to healthcare resources.

---

## ✨ Features

-  **Fast Performance:** Built with Next.js 15+ App Router for rapid page loading and optimal UX.
-  **Modern Interface:** Styled with custom components and optimized typography using [Geist](https://vercel.com/font).
-  **Responsive Layout:** Tailored for seamless navigation across mobile, tablet, and desktop devices.
-  **Secure & Scalable:** Structured for secure data handling and smooth integration with healthcare APIs.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** Tailwind CSS / CSS Modules
- **Font:** [Geist](https://vercel.com/font)
